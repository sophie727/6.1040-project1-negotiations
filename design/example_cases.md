## The Job Offer

**Author:** Sophie Liu
**Case Name:** The Job Offer

**Issues:**

- Start date
    - option name: January 1; universal value: 0 (0 days after the first date option)
    - option name: March 1; universal value: 58 (58 days after the first date option)
- Salary
    - option name: $80K; universal value: 80,000
    - option name: $120K; universal value: 120,000
- Health Insurance (discrete, so no universal values)
    - option name: Full Coverage
    - option name: Half Coverage
    - option name: Not included
- Bonus
    - option name: $0; universal value: 0
    - option name: $10K; universal value: 10,000
- Position title (discrete, no universal values)
    - option name: assistant manager
    - option name: senior manager
    - option name: director

**Roles:**

- Manon, the employer
    - With the payoffs:
        - for start date, Manon weights January 1 at 800 and March 1 at 0.
        - for salary, Manon weights $80K as 500 and $120K as 0.
        - for health insurance, Manon weights them all the same (0).
        - for bonus, Manon weights $0 at 100 and $10K at 0.
        - for position title, Manon weights assistant manager at 0, senior manager at 100, and director at 200.
    - And a BATNA of 1000.
- Hiro, the hiree
    - With the payoffs:
        - for start date, Hiro weights January 1 at 0 and March 1 at 300.
        - for salary, Hiro weights $80K as 0 and $120K as 600.
        - for health insurance, Hiro weights full coverage at 300, half coverage at 150, and not included at 0.
        - for bonus, Hiro weights $0 at 0 and $10K at 100.
        - for position title, Hiro weights assistant manager at 0, senior manager at 100, and director at 200.
    - And a BATNA of 1000.

The confidential briefings for the roles can be, I'm sure, generated by AI. They should capture all of these payoffs and issues under question, and give something of a backstory to them.

# Prompt for generating the confidential briefing

(you should generate a prompt that covers the following)

The confidential briefings can, I'm sure, be generated by AI. They should capture all of these payoffs and issues under question, and give something of a backstory to them. In particular, the confidential should be formatted as a markdown, with headings; the first section will describe the situation (e.g. Hiro is discussing a job offer with Manon for a management role at XYZ company. This section should also include details on what the status quo of the industry is.). The second section will describe the role's priorities with respect to the situation (e.g. Hiro cares a lot about health insurance, because he's a sickly person. He also cares immensely about the salary. He cares less about the bonus, since he sees bonuses as less reliable than a salary. Hiro already has another job offer for [job offer details summing up to 1000 points]). The third section will explicitly lay out the payoff values.

MAKE SURE THAT the confidential briefing is CONSISTENT across different roles in a case: for instance, if Hiro's confidential says that Manon has been in contact for the last 5 weeks about a role at Pineapple, then Manon's confidential should say the same.

ALSO MAKE SURE THAT the confidential briefing is CONSISTENT with the issues and payoffs already laid out numerically in the case. Anything that's not in the case can be made up, as long as the overall narrative makes sense.
